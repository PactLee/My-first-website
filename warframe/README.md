# 워프레임 도우미

워프레임의 모든 워프레임·무기·모드·아케인·성유물·자원·적 정보를 검색하고,
**어떻게 만드는지(제작 재료·크레딧·시간)** 와 **어디서 파밍하는지(드랍 위치·확률)** 를 보여주는 웹 도우미입니다.

- 명칭: 게임 내 **공식 한국어 명칭**을 사용하고, 공식 번역이 없으면 **영어 명칭**을 그대로 표기합니다.
- 기능
  - 한국어/영어 이름 검색 (부품 이름 "볼트 프라임 섀시"로도 검색 가능), 카테고리·프라임·볼트 필터
  - 제작 방법: 크레딧, 제작 시간, 필요한 부품/자원, 부품별 획득처와 확률
  - 획득처: 미션(행성/노드/로테이션), 성유물(정제 단계별 확률, 볼트 여부), 적 드랍
  - 성유물 보상표, 자원 사용처, 적이 떨어뜨리는 아이템
  - 제작 계획: 여러 아이템의 필요 재료 합산 + 보유 체크(브라우저에 저장)
  - 공식 위키 / 팬덤 위키 바로가기

## 실행

`fetch`로 데이터를 읽기 때문에 `index.html`을 파일로 직접 열면 동작하지 않습니다.

```bash
cd warframe
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

GitHub Pages로 저장소를 배포하면 `/warframe/` 경로에서 바로 사용할 수 있습니다.

## 데이터 갱신

데이터는 [WFCD warframe-items](https://github.com/WFCD/warframe-items)(공식 드랍 테이블 + 게임 내 번역 기반)에서 생성합니다.
게임 업데이트 후 최신 데이터로 다시 만들려면:

```bash
npm pack @wfcd/items
tar xzf wfcd-items-*.tgz
python3 warframe/tools/build_data.py package/data/json
```

## 알려진 한계

- 일반 워프레임 부품(섀시 등)을 만드는 데 드는 세부 자원은 원본 데이터에 없어 위키 링크로 안내합니다.
- 적 이름, 노드 이름, 일부 미션 타입은 공식 한국어 번역 데이터가 없어 영어로 표기됩니다.
- 이미지는 cdn.warframestat.us에서 불러옵니다.

Warframe은 Digital Extremes의 상표이며, 이 도우미는 비공식 팬 제작물입니다.
